# 旧文件工作流兼容区（不用于新任务）

本区保留 **109 份** v0.7.5 仍供显式 `mpres legacy` 使用的模板，原始字节不变。
这些模板描述 assignment 三联单、六阶段文档、旧线程注册和旧版反馈机制，**不代表当前课件生产规范**。
移出 `templates/` 是为了消除两个任务入口并列造成的误读，不是宣布旧机制已全面更新。

## 允许的用途

维护未迁移旧任务、解释历史记录、运行兼容回归。旧 Python 调用点显式读取本目录。
新任务仅由 `Service.create()` 读取 `templates/compact/`；导入旧稿不等于重新运行旧流程。

## 禁止的用法

不要扫描本区为新 worker 拼提示；不要把这里的 TASK、SELF-CHECK、stage 文档复制到
SQLite 任务。不要用 legacy 绕过固定主题、源码规约、用户确认或单一状态源。
版本间升级也不允许从这里恢复常驻 author-coordinator。

## 维护与退役

兼容模板原则上冻结，修兼容 bug 时单独测试；不继续把新教学意见追加到旧政策中。
完整清单、当前／兼容分类和消费路径见 [文档盘点](../../docs/DOCUMENTATION-INVENTORY.md)。
只有相应调用点和兼容测试一同退役时，才删除模板。旧历史说明见 `docs/legacy/`。
