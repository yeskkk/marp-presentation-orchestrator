# 教学资源设计

## 1. 学习目的与输入

根据已建立的任务上下文、当前数学对象和学习困难，说明资源需要让学生观察、比较或推断什么。
资源是解释的一部分，不是填补空白或证明使用了多媒体。是否单独委派本角色取决于任务，
不因存在该 skill 就创建一个常驻资源线程。交付范围以本次授权为准。

## 2. 从数学定义生成表示

凡位置、数值和关系可由定义计算，应从同一数学数据源生成各个对象、标记和标签。
先核对对象类型、单位、维度及退化情形，再选择能忠实表达目标关系的表示方式。
坐标映射、比例、截取区间、投影与离散近似都有可能改变直观，必须识别其对结论的影响。
标记与标签从计算结果产生，不能为视觉方便另写一套位置后声称已经验证。
用适合问题的关系检查结果，而不仅检查文件能否生成或图是否外观整齐。

## 3. 工具选择与资产修改

根据项目当前支持的接口和权限选择工具，不从长期教学原则推断某种软件永远可用。
生成式资产保留其定义、数据和可复现入口；修改数学定义后重新生成，不直接改派生图形。
旧资产可作为只读证据；新的工作副本中验证版本和环境差异，不能覆盖历史证据。
超出现有工具能力时提出明确实现与核验方案，不伪装为已经支持的输入，也不自动安装依赖。
具体命令属于工具文档和请求中的执行契约，不作为每次语义任务必读的方法库。

## 4. 资料与现实证据

读取实际出处并核验与使用有关的时间、范围、量、单位和证据性质。
材料必须进入模型、计算或解释；来源的新近性与相关性分别判断，不互相替代。
区分实测、估计、模拟与假设，明确它们允许的现实推断。引用保留必要归属和可访问位置，
制作者的内部检索坐标不转成学生阅读材料。未核验的内容不能被包装成事实。

## 5. 资源进入课堂

为资源配一个明确观察任务，并说明对象与符号的对应及必要限制。
交互资源应规定可改变的量和应注意的变化，不把开放操作本身当成学习结果。
删去无助于当前观察的装饰与无依据澄清，但保留影响数学理解的条件。
交接实际资产、生成依据、可复现入口与必要说明；生产验证状态和缺口留在结果层。
