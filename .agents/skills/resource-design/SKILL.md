# 资源与图示设计

根据教学目的选择图示和资源，而不是为了丰富页面而装饰。优先使变量、单位、比较和因果关系清楚。
使用项目提供的来源说明素材出处和适用范围。外部资源没有实际读取时不得声称已验证。
GeoGebra 采用链接，引导教师或学生明确操作与观察目标，不嵌入远程应用；不要求资源去重。
公式、坐标图和几何图必须从数学定义计算生成；不得手写 SVG 图形坐标。只有任务明确允许代码绘图时才提出/编写相关代码，
不能自动安装软件、执行下载或改变任务政策。提交实际资产或资源建议，说明它解决哪一个认知难点。
资产不得包含脚本、远程加载或越界路径；图形意义和标签必须经作者/审核者理解，而不依赖视觉装饰。

## 项目表达边界

布局由项目全局主题提供，author/editor 不拥有 CSS 或页面样式。禁止原始 HTML block、
inline HTML、内嵌 SVG、临时 class/字号/图片尺寸。只用规范 Markdown、数学公式与
外部图片引用；仅 slide-id 与 core/support 是机器注释白名单。内容放不下就删冗余、
拆推导、拆页，不能缩字、挪公式、修改主题或把正文截图成图片。源码提交前运行
`mpres source check <output>`。制作回执只写结果 JSON，不写学生页。

## 计算式几何图

直线交点、二维线性变换、向量投影优先使用 `mpres figure build <name>.plot.json`。
输入只写方程、向量和矩阵，不写像素、交点答案或样式。计算式 SVG、数学输入
和配套 `.py` 放在 `assets/<unit-id>/`；引用外部 SVG，不内嵌 HTML。
不得手改生成 SVG；修改数学数据后重新生成，再执行 `mpres source check`。
生成器只证明图与给定数学对象一致；例题是否恰当仍须作者理解、首次审核检查。
不支持的图种先提出所需数学构造和工具，不能冒称已由计算式门禁验算。

## 来源与图示必须参与学习

近期材料需要在变量、单位、模型、计算或结论解释中发挥作用，不能孤立列日期/新闻
证明“近几年”。图示标签只解释当前对象，不添加没有上下文的地理误读等免责声明。
必要事实出处可简短展示；内部提取文件行号仅留在来源记录，不能变成学生参考文献页。

## 继承旧数学图

版本1/2/3的 `.plot.json` 可由项目生成器读取，数据是数学定义，不是已验收证明。
新修订工作副本中的图会按当前绘图库重新生成；不要把历史 SVG 复制回去以恢复外观。
已有作者草稿不自动覆盖：需要更新时在自己的输出目录调用 `mpres figure build`。
只改数学数据并重生成，不手改 SVG、主题或增加局部图片尺寸；错误位置留在内部处置里。
