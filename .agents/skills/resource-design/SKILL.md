# 资源与图示设计

根据教学目的选择图示和资源，而不是为了丰富页面而装饰。优先使变量、单位、比较和因果关系清楚。
使用项目提供的来源说明素材出处和适用范围。外部资源没有实际读取时不得声称已验证。
GeoGebra 采用链接，引导教师或学生明确操作与观察目标，不嵌入远程应用；不要求资源去重。
公式、坐标图和几何图应可由确定性代码或 SVG 表达。只有任务明确允许代码绘图时才提出/编写相关代码，
不能自动安装软件、执行下载或改变任务政策。提交实际资产或资源建议，说明它解决哪一个认知难点。
资产不得包含脚本、远程加载或越界路径；图形意义和标签必须经作者/审核者理解，而不依赖视觉装饰。
