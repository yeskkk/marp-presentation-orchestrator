# 资源设计：图和资料必须解决认知问题


## 1. 先问资源改变了什么理解

说明学生要看见的关系、比较或变化，再选图/数据/交互资源。装饰、热词和孤立统计不计作案例。
本能力由 main/作者按需使用，不表示正常 runner 会另建一个 resource job 或第五类结果 schema。
在现有授权输出目录交资产/建议；共同约束见 [learning-contract](../_shared/learning-contract.md)。

## 2. 数学图的单一数据来源

从方程、向量、矩阵或函数定义计算所有对象。曲线、交点、标签数值共用结果，
不能曲线用一个数据坐标、圆点另填像素，再声称“Python画的所以正确”。
先检查量纲/维数和退化情况，再选坐标范围/等比例显示，并解释图与公式的对应。
图内标签应服务当前对象，不额外创造“不是地理位置”等无上下文免责声明。

## 3. 现成计算图怎么用

直线交点、投影、二维线性变换优先项目 `mpres figure build`。输入按 generator 支持 schema，
不是任意 CSS/字号/目标交点。方程一般式支持垂直、平行和重合；相交点必须代回两式。
assets/<unit-id>/ 中保存 .plot.json、SVG 和生成入口 .py，再由 Markdown 外部引用。
只改数学输入并重生成，不能手改 SVG。`figure check` 使用项目计算，不执行作者/归档的 Python。
未支持图种给明确工具和数学验算方案；不能伪装成三种受控图之一，也不能自动安装软件。

## 4. 旧资源与可复现性

新编辑副本可读取旧版本1/2/3输入并重生成，不修改历史证据。不要把旧 SVG/主题复制回去。
已有草稿不自动刷新，需作者在其允许目录明确重生成。配套数据和入口随直接目录交付，
但文件存在不等于在当前部署环境已通过原生浏览器或完整课件检查。

## 5. 现实资料与交互资源

核实实际读到的原出处、事件日期、量/单位、可用范围，解释它参与哪个模型和结论。
不能为了“近几年”把无关新闻贴到末页；模拟数据披露与事实来源分开。
GeoGebra 可以链接，写清要改变什么、观察什么，不嵌远程应用；没有去重硬要求。
教材内部摘录行号用于制作定位，学生只保留必要可访问出处。来源未核验就说未核验。

## 6. 交接给内容作者

交付图/数据/脚本及简短的数学关系、观察任务和限制。必要说明融入学生解释，
资源验证/缺口回执留内部。教材使用获准文本摘录，不默认打开原始PDF；网络和执行权限服从任务提供范围，
不截图/OCR/视觉模型查PDF、不编辑 theme、不写状态或建立独立管理模板。
