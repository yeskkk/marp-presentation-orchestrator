# GeoGebra resource links

## Purpose

GeoGebra links are optional enrichment for genuinely dynamic mathematical exploration. They do not replace the explanation, example, proof, diagram, or exercise that must remain understandable in the PDF.

## Bounded search

- First decide whether the unit could benefit from an interactive construction or parameter exploration.
- If relevant, use no more than the configured number of targeted searches and restrict them to `geogebra.org`.
- Use a specific public material page of the form `https://www.geogebra.org/m/<resource-id>`.
- Check the title, apparent author/source, mathematical topic, level, language, and direct relevance before selecting it.
- Select at most the configured small number of links. If nothing clearly useful appears, record the outcome and stop.

## Link-only use

Use a normal Markdown hyperlink, for example:

```markdown
[GeoGebra：用滑块观察二次函数参数](https://www.geogebra.org/m/RESOURCE_ID)
```

Do not use remote images, iframe/object/embed/script elements, `GGBApplet`, `deployggb.js`, `ggbBase64`, screenshots, preview images, downloaded applets, QR-code screenshots, or copied thumbnails. The link must be supplementary; the slide must remain complete when offline.
