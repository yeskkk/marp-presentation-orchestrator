# Unit handoff minimum

A lesson author hands off: `section.md`, namespaced local assets, `UNIT-MANIFEST.yaml`, `SELF-CHECK.md`, and a durable checkpoint. Slide IDs, semantic-object IDs, terminology, and example IDs must match coordinator registries. A section fragment contains no YAML frontmatter and does not redefine global theme directives.


The handoff also includes `GEOGEBRA-RESOURCES.yaml`. It records whether a bounded `geogebra.org` search was relevant and attempted, the queries used, any selected links, or the reason no link was selected. Selected resources must appear in `section.md` only as ordinary Markdown hyperlinks.
