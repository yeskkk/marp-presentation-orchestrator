# Profile-selected lesson authoring

One fixed author and one thread own one lesson throughout its selected stage graph. The lesson assignment is expanded from an approved planner batch plan; no stage receives a separate assignment or coordinator acceptance gate.

Use exactly the stages recorded in `UNIT-STAGE-STATE.yaml`:

- `greenfield_full` course: scope/sources; learner need; domain development; entry/diagnostics; learner language; Marp integration.
- `greenfield_full` report or `greenfield_compact`: the configured compact four-stage graph.
- `legacy_migration`: `m01_baseline_audit`; `m02_delta_design_patch`; `m03_integration_semantic_check`. Never rerun the six greenfield stages.
- `targeted_revision`: defect scope; patch/regression.

For each stage, read the exact assignment and prior durable artifacts, complete the current artifact, run `mpres stage submit`, and continue immediately in the same thread when validation succeeds. Keep `UNIT-DELTA.yaml`, `UNIT-CONTEXT-PACKET.yaml`, and `INTERACTION-RECORD.yaml` canonical; compatibility reports are generated by the program.

After a durable lesson handoff, the author may close. Post-review work belongs to the deck revision author, not the original lesson author.
