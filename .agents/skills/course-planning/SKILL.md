# 课程规划

## 1. 任务与职责边界

把用户意图转化为作者能执行的学习路线：学生从什么基础出发，要获得哪些认识和能力，
各课为什么按这个顺序展开。规划不是把教材目录拆成相同页数，也不是生成运行步骤清单。
已确认任务的普通续跑不重新规划；指定旧稿的改良遵守返修范围，不扩展为全课程重写。
main 整理 TASK.md，delegated planner 只提出所分配范围的建议，不代用户确认。

## 2. 输入与要求整理

依据已建立的 TASK 上下文、当前用户修改、可访问教材和有效历史反馈工作。
分别整理学习目标、受众基础、教学取舍、资料约束和交付范围，避免把执行设置误当教学内容。
核对证明深度、概念覆盖与受众兴趣是否相容；不能从数学严谨推导出必须保留全部证明。
继承旧任务时区分仍有效的教学偏好与已废弃的运行办法。缺项和冲突应当具体指出，
不把一份形式完整的计划当成已经消解了歧义。

## 3. 从目标安排学习进阶

先确定学生最终需要理解、辨别或操作的对象，再反推必要概念、表示与条件。
把一个目标分解为可在课次中完成的认知增量，标清哪些关系必须先理解，哪些可以后置。
每课安排一个可以进入的问题、一条逐步发展的解释路线和可检验学习结果的活动。
课次按授课单元组织，不自动等同于教材章节；相邻课的交接应说明旧认识怎样支持新问题。
时间、核心与补充安排服从 TASK；它们服务教师调度，不直接变成学生页标题和清单。

## 4. 安排例子、表示和活动

例子要体现目标对象的关键结构，能解释选择它的理由，不能只有可计算数字。
选择对当前关系有帮助的图形、符号、数据或语言表示，安排必要的表示转换与观察任务。
练习应让学生作出与目标相同类型的判断；错误选项或辨析题应对应有根据的理解困难。
答案、提示和反馈的出现顺序应保护学生先思考的机会。活动数量与长度由任务决定，
不把固定页型、固定题量或某次历史课程的时长当成所有课程的配方。

## 5. 资料及现实联系

先确定资料在哪里影响学习，再核对可用来源、事件日期、单位、证据性质和适用范围。
现实材料必须参与数学对象的建立、求解或解释；新近的发布时间本身不是教学用途。
无法获得真实数据时明确选择可核验材料、经允许的模拟或待补资料，不能伪装事实来源。
图示规划写数学关系和观察目的，不写人工像素位置。内部材料定位服务制作者，
学生可见出处只承担必要的归属或证据说明，不替代实际解释。

## 6. 计划检视与交接

逐课检查：入口能否被目标受众理解，关键概念是否有动机，必要条件是否可见，练习能否
暴露目标困难，相邻课是否衔接，资料是否真实可达。发现拥挤时调整范围或补充层次，
不预先要求作者靠缩字或冗长解释把所有材料塞进去。
按当前 plan schema 提交 presentations/units 与必要 teaching 选择。总体边界留在 TASK，
课次细节只在批准计划维护一处。待决事项与建议分开，不自造阶段文件或宣布运行已获批准。
