# Planner checklist

- Audience profile includes prior knowledge, likely weaknesses, and expected gains.
- Time calibrates volume but does not mechanically partition concepts.
- Presentations and content units are explicit.
- Pilot/each/all delivery behavior is explicit.
- User was reminded of three rounds, five channels, no screenshots, medium default reasoning, PDF-only Marp, disabled-by-default Python figures, and optional GeoGebra-only hyperlink enrichment.
- Only top-level TASK.md uses a hash confirmation gate.
- Every presentation has author-coordinator, lesson-author, review-coordinator, specialist-reviewer, and release-coordinator assignments.
