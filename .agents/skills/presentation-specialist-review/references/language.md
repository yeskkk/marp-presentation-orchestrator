# Language channel

Check student-visible language and terminology: natural syntax, explicit subjects and objects, title clarity, labels, ambiguity, translationese, repeated mechanical templates, internal production vocabulary, and consistency with the task's language standard.

- Check that GeoGebra hyperlink labels are descriptive learner instructions rather than bare URLs, “点击这里”, or unexplained resource titles.


For genuinely problematic sentences, review in context rather than as a forbidden-word scan. Record the excerpt, referent, intended proposition/action, discourse link, syntactic head, modifiers, possible segmentations, standard object, ambiguity and recommended revision. Use this structure only where it clarifies a real learner-facing problem; do not fill it for every sentence.
