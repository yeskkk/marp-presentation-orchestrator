# Pedagogy channel

Check motivation, concept chains, prerequisite activation, timing of precision, positive/negative examples, transfer, explanation of method choice, return to motivating questions, difficulty slope, and whether tables or visuals genuinely serve instruction.

When a GeoGebra link is present, check that it names a concrete optional learner action and does not replace the explanation, proof, example, or required classroom figure.

- Check that any GeoGebra link has a clear optional exploration task and genuinely benefits from dynamic manipulation; reject decorative, redundant, or quota-driven links.
