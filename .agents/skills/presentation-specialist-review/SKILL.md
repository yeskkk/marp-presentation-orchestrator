# Specialist review

- Initial: full deck; new findings allowed.
- Incremental: prior findings, changed areas, and regressions only; new IDs must be marked `regression`.
- Final: full deck; new findings allowed.
- Terminal closure is not specialist review.

Every finding has a stable ID, exact location, issue, learner impact, acceptance criteria, and verification method. Do not edit author source. Do not use screenshots or model vision. A zero-finding report still records scope and evidence.
