# 分配通道细则（每次只读取一个主通道）

## domain_accuracy

### 数学正确性

先识别对象、定义、维度、单位、适用条件，再核关键变形/结论/例题。计算能复算就复算，
图形声称的关系与公式核对；正交、交点、秩、唯一性不要仅凭图看起来像。
例如参数化 $p+tv$，检查 $p$ 满足非齐次、$v$ 满足齐次，取简单 t 代回；不要只审 TeX 是否美观。
概念用通行术语，类比不能覆盖条件。准确数学不等于要求少证明课程增加证明训练；
指出缺少改变结论的理由/条件，不凭“未给完整证明”自动判低质量。
提出建议前核对原题，不能把另一个例题的常数项套过来。

## pedagogy

### 教学设计

看学生正在解决的问题、概念出现的动机、例子是否推进理解、相邻课是否断层。
学生兴趣弱/证明 minimal 时，不用“形式完整”保护冗长证明；也不能把所有数学抽成泛泛故事。
案例应连入模型和结果；孤立“近几年新闻”不是现实应用，单引教材一句话不是解释。
诊断题检查真正易错点，题干和答案分开，迷惑项可解释。核心/补充是教师节奏，不能当学生结论。
改善建议说具体要增、删或移动的教学内容，不只说“加强互动”。

## audience

### 学生试读最终汇总

student 和 production_language 的分段步骤由 runner 安排，先前问题已经有真实页范围。
本次最终 run 对照历史反馈汇总，不重新代作者修改，不再从头执行别的四个通道。
保留前序 findings 原文，不静默删去不方便处理的问题；具体重复条目可说明，但不能让必要项消失。
以学生具体所得和学习损失删除反事实为准，不用“属于教学内容/不是自夸”保护空话。
已读历史反馈，不能宣称盲测，更不是实际学生实验。

## language

### 对学生说清楚

术语规范、记号一致、指代明确、句子主语和对象清楚；不是只找错别字。
“目标：定义/分别论证”“本课核心约40分钟”“已按要求……”先问是否在对制作者汇报。
数学含义必须保留，但呈现可从学生问题开始，不能机械将“定义”全部替为“知道”。
结论是具体数学认识，不是“分别论证/保证一般维数”的空泛口号。
引用要服务当前解释；内部TXT行号/孤立摘录不作为学生阅读清单。必要事实出处不能误删。

## layout

### 信息组织与阅读顺序

根据实际源稿、提供的机械报告与允许资产，判断一页的主问题是否清楚、图文是否可对应、
题目提示答案顺序是否合理、表格列义是否明确、信息是否拥挤到影响理解。
不要声称已视觉检查没有提供的页面。溢出由真实报告定位；数学或学生理解不能由零溢出推出。
建议删冗余、拆推导/宽表、调整内容顺序；不要求作者 CSS、HTML、缩字或移动 MathJax SVG。
若合法 Markdown 表格在全局主题下无边框，这是项目工具/主题问题，不让 author 嵌 HTML 应急。

## repair

### 确认返修范围内的审核

对 repair_scope 确认的全部问题形式在选定整稿排查，不能只看用户例举页；不访问未选课件。
每种形式用 repair_checks 的 allowed status 与真实页；reviewer 的 issue 必须形成 finding。
这不是根据作者声明验修；依据本轮提供的冻结/历史发布证据独立判断。
允许删页意味着可以建议有理由的删/并，不意味着 reviewer 直接修改 source。
