# 学生试读窄步骤（每个请求只运行当前 phase）

## student

### 当前段学生阅读

只读 packet.slides 的当前页段与相关资产，按 read_slide_ids 顺序完整覆盖。
先用一句话说这段学生正在解决什么、实际能理解什么；再找需要猜符号、条件、指代、
图与公式联系或突然换背景的地方。不同时重做数学专家、语言和版式全部工作。
对每个真实困惑引用原片段并说明学习影响，允许 observations/findings 为空，不凑表扬。
“这里有定义、例子和结论”是目录，不是学生所得；说明能判断或做到什么。
不参考作者的 readback/自检证明，也不声称这种模拟读法等于真实学生实验。
返回本段精确 phase/read_slide_ids/summary/observations/findings；当前 schema 未要求时
不要自行填生产状态或伪造已读后续页。

## production_language

### 当前段学习价值检查

不仅查合规自夸；逐句问“删去以后，当前数学学习具体损失什么？”
attention_candidates 是待判断信号，不是自动删词表，也不是完整问题清单。
对每个候选给 keep/remove/rewrite/move_to_notes、具体学习损失与理由。
删/改/移必须对应本步 findings 数组内同页 finding 的零基索引；keep 的 finding_index 为 null。
不要把模型下游身份或假意见填成字段。

例：“先修：平面直角坐标系”只是备课清单，可改成读坐标的小问题；删清单不损失当前数学，
实际基础不能忽视。“这些数字为模拟，不是实测”若影响现实结论必须保留或简短改写。
“假设功率恒定”定义模型，不能因带假设就删；“教学假设已符合要求”是制作说明，应移走。
“不是地理位置”若没有真实误解上下文，不值得占用注意力；直接说明坐标表示哪两个量。
不以“不是自夸/可以避免误解/属于教学内容”为唯一保留理由，不强制正面 observations 数量。
只回应当前段，不编辑源码、不跳过后续段，最终汇总由后续 run 请求发起。
