# Deck revision authoring

Start only after atomic review aggregation. Read the complete frozen source, all five current channel reports, the finding registry, `REVISION-ROUTING.yaml`, `REVIEW-PLAN.yaml`, and `AUTHOR-CONTEXT-PACKET.yaml`.

Own every finding and every cross-unit consequence in one canonical deck. Do not reopen original lesson authors. Record one author response per finding, preserve finding text as historical evidence, update the complete deck, reconcile terminology/objects/continuity, and complete the modification checklist.

Rerun all deterministic author gates. The deck does not return to reviewers. Successful response coverage, checklist completion, and mechanical gates move it to `release_ready`, where the release coordinator is created just in time.
