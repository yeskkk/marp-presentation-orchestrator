# 学生试读的阶段焦点

## student

### 当前段的实际学习体验

按 read_slide_ids 完整阅读本段及相关资产，说明学生面对的问题和能获得的具体认识。
指出需要学生自行补齐的对象含义、条件、指代、表示对应和推理过渡。一般讲授可核对允许的上下文；
随堂练习必须隔离题页逐题检查全部子问，不得用邻页、答案或备注补题设。缺必需数据应报告，
不把“忘记前例矩阵”当成学生问题；已学知识和由本页条件足以确定的对象不用机械重复。
只报告有根据的困难，不同时执行其他四通道，不以作者自评作证，不要求正面 observations 配额。
使用已建立的 TASK 理解；不重新阅读全文。返回本次 phase/read_slide_ids/summary/observations/findings。

## production_language

### 当前段的注意力价值

逐段问删除后对当前学习具体损失什么。attention_candidates 是待判断信号而非自动删词规则。
承载含义、必要条件或证据限制的内容可保留；只记录教师安排和制作过程的内容应移出学生稿；
内容必要但表达不当应改写。澄清误解需有真实语境，引用和总结需承担实际解释功能。
按 schema 对候选给 keep/remove/rewrite/move_to_notes、具体损失与理由；keep 的索引为 null，
其他处置指向本步同页 finding。不能只凭泛泛教学标签作决定，也不静默跳过候选以宣布合格。
不编辑原稿，不提前读取未给出的页面。最终综合留给后续 run，不在每段重做历史反馈审计。

## synthesis

### 完成覆盖后的最终审核结果

依据已经完成的学生阅读与注意力检查，结合本轮历史反馈整理 review-result。
不从头重读 TASK 或重复所有分段，不把模拟试读宣称为真实学生研究。
前序已接受的 findings 由程序完整合并，不要重新逐字输出。只提交新的语义发现，
以当前请求提供的 finding_refs 关联反馈和返修要求，说明主要困难、学习影响和所依据的范围；
不为方便结案删除问题，不借汇总扩展到作者修复验收。补齐真实反馈证据和确认范围内的检查。
