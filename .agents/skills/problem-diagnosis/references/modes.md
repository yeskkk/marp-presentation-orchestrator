# 诊断模式

## bounded

### 给定证据的只读诊断

按现象、证据、根因假设、核验方法、建议范围组织。只覆盖已提供的目标和相关证据。
需要补证时明确最小必要材料；更广的风险只能标为推断，不能假称已检查。

## expansion

### 用户返修确认前的问题展开

先解释投诉背后的质量要求，再展开它可能在对象、关系、条件、表述、依赖或受众体验上的表现。
相似问题要说明与原问题的关系，不能塞入无关通用清单。逐项区分 observed 和 possible，
只为实际观察填真实页位。给 detection、correction、non_goals、acceptance_criteria、source_needs。
代表性稿件不是整批检验结果；提案需要用户对精确范围确认，不直接启动修改。
