# 已确认返修范围的审核附加说明

完整阅读所选冻结稿，优先检查已确认问题族及相关形式；同时按各自通道发现其他具体问题。不要把初始返修目标当成过滤 findings 的白名单，不能因为“不属于这次投诉”而忽略数学、教学、语言、练习或版式问题。
作者随后必须逐项处理五通道的全部 findings；无须为同一所选稿内正常的质量纠正额外申请扩大问题族。确实涉及未选课件、教学取舍冲突、删除/合并页授权、缺材料或工具权限时才交 main 决定，不伪造授权，不自动追加 reviewer 验修。
按协议对确认问题形式给真实 repair_checks；其他发现直接进入 findings，不强塞到某个问题族。区分观察到的问题与风险假设，反馈/返修 checks 引用同一 finding，避免重复。
历史发布、已读覆盖和作者自评不构成本轮新评价维度已通过；评价绑定当前源码版本与明确维度。标题、正文、题干选项、答案、图注表头和总结都在学生可见表达范围。
