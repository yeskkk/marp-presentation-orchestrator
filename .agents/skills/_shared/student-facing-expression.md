# 学生可见表达：清楚、自然、各句分别起行

标题是可选组件。只有帮助定位内容、提出真实问题或表达重要关系时才保留。题干、公式或图示已清楚成页时可以直接开始；删除标题后不自动补写另一句，不设标题配额，不强迫结论句/问句标题。规范的概念名称可以直接作标题。页定位使用 slide ID，不依赖标题；标题不得混淆对象或泄露练习答案。

用本学科正常的术语和具体对象说清关系。类比和日常解释辅助理解，不替代已经学会的准确概念；学生不应先把一句“跨领域新话”翻译回本学科才懂。没有错字、没有改变算式结果，并不等于表达合格。

独立句子分别起行。使用合法 Markdown 硬换行（行末两个空格或反斜杠）或按逻辑分段；不能只靠源文件普通回车、空格对齐、HTML、局部 CSS 或缩字。一句话允许自然折行，不要求一个长句只能占一条显示行，不把所有句子变成项目符号。“若……，则……”及定义条件和公式的衔接保持完整。

优先具体主语、明确动词、必要的因果/对比/承接。删去名词堆叠、抽象串词、重复总括和制作审查腔，但保留解释所需连接。朴素不等于干巴，亲切不等于俏皮；不用“轻松掌握”“一眼看懂”等口号、无关故事或固定的设问—揭晓模板制造活人气息。

检查全部学生可见文字：标题、正文、题干、全部选项和子问、答案、图注、表头、总结。相同模式可合并为一个 finding 并列出受影响页，不写逐页自证表。误导、概念替换、系统性不清楚可以是 major；不能一概以“个人文风偏好”放过，也不把普通风格差异都判成错误。

编拟生活算例继续按共同边界处理：情境和数量关系合理、单位和条件完整即可；不为了证明它真实发生而查新闻、实时价格或统计，不冒充真实数据，也不强加免责声明标签。
