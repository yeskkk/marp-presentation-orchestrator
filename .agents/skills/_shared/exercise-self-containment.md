# 随堂练习必须单页独立成题

本规则覆盖所有实际要求学生作答的随堂练习，包括判断、诊断、思考、投票、计算和追加子问，
不以标题是否写“练习”区分。题干、全部子问、选项，以及作答必需的具体数据、对象、图示、
单位和条件，必须在同一张题目页内完整呈现，或由本页给定条件足以确定。
学生可以运用已学知识，但不得被要求记住或回看其他页面的实例矩阵、数字、图形或临时定义。
答案页、讲者备注和教师口头补充不能补齐题设；仅在注释中列出对象不算学生可见。

答案和讲解可以另页；题目不能跨页。标准版式一页放不清的题，应减少非必要子问、简化数据
或换成考查同一学习目标的题，不能拆题干、缩字、删必要条件或改名“思考”绕过限制。
多页讲授例题可以用于解释，但不能算作独立随堂练习，也不能以不让学生作答来虚报练习覆盖。

作者与编辑逐题检查所有子问，修题同时复算答案并同步图示和引用。教学法与学生视角审核
必须隔离题页：只凭本页学生可见内容及本页图示判断题设充分性，不用邻页或答案填补。
该检查并入现有通道，不新增审核角色，不自动增加作者修改后的全套复审。
缺必需题设是阻断作答的问题，应形成明确 finding；不能仅记无碍交付的排版 warning。

不要机械要求所有字母展开：已给 A=LU 及完整 L、U，可以确定 A；一般性质题只需给足条件；
已给行列式变换关系足以反推结果时无需再列整个矩阵。关键词只能定位候选，不能自动证明
通过或失败。指出缺哪项必要信息及其影响，而非泛泛要求“加上下文”。
