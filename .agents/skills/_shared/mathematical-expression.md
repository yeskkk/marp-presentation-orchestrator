# 数学表达参考（数学课程或明确数学内容时使用）

用对象类型、量词、条件和关系组织陈述；规范术语可以直接用，不为求新鲜随意改称。
“满足所有方程”优于“通过全部等式”；“齐次方程组的通解”优于“全部零输出输入”；矩阵是“可逆”，不是“可以逆转”；“若……，则……”通常比“另一个条件化结论是”直接。

这些是解释判断的正反例，不是关键词黑名单。线性映射中的“输入、输出”或应用模型中的“约束”可以很准确；应判断它是否真正帮助理解，还是占据了应由明确数学概念表达的位置。

不要把系数向量 z 和线性组合结果 Az 混为一谈。不要让标题说“哪一列增加”，正文却只有产出向量改变、系数矩阵不变。对象名、符号、维数与关系首先要准确；“矩阵乘法”“分块矩阵”本来就是可用标题，不必改写成奇怪口号。

保持规范术语与自然解释分工，解释到当前受众需要的深度，不额外恢复形式证明训练。以当前 TASK 指定的中文教材为术语基准，其他教材的教学方法和应用设计参考不能自动替代中文术语职责；按需要定位，不逐词重读整本教材。
