# GeoGebra resource discovery

First decide whether dynamic manipulation is genuinely useful. If not, record `not_applicable`. If yes, make at most the task-policy number of `site:geogebra.org` queries and select at most the configured number of resources.

A selected resource must be a concrete public `https://www.geogebra.org/m/<resource-id>` material and have `verification_status: verified`, visible title/author when available, verified activity, and verification time. `not_checked`, unavailable, or content-mismatch resources may not enter the deck.

Use only an ordinary descriptive Markdown hyperlink. Never embed, download, screenshot, preview, thumbnail, QR-code, iframe, script, object, or mirror the resource. The PDF remains complete without opening the link.
