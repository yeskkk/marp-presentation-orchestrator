# 设计约束

## 运行事实只有一处

SQLite 关系模型管理配置、job、attempt、session、artifact、gate、finding 和发布记录。
文档解释它们的关系，不再各建一份 YAML 状态镜像。外部调用和渲染不放在写事务内。
文件系统发布与数据库提交通过暂存/幂等收敛，不能宣称 SQLite 可以回滚模型调用。

## 语义与机械分离

main 处理用户需求和真实决策。十个 skills 只定义教学判断；runner 决定依赖、容量、重试、
检查与交付。教学结果字段不能宣称 gate/capacity/approval 成功。作者自修后不新增验修 reviewer。

## 文档与模板同样有生命周期

当前用户模板只有三份；旧109份过程模板属于显式兼容入口，位于 compat/legacy/templates。
分类和清单自动盘点，不因文件旧就直接删除，也不把旧内容继续当最新规则注入模型。
流程互斥/条件分支写在一个明确位置。实现未支持的能力写为限制，不在说明中提前宣布完成。

## 输入预算是约束，不是静默截断许可

必读正文完整提供，相关资源按需；宿主实际读取计 usage。增加文档不等于强制注入所有材料。
条件性角色说明必须经运行器选择，不能让每个 reviewer 同时承担五个角色。

当前代码路径详见根 README，维护验收详见 VALIDATION.md；旧版本说明在 legacy 区仅作历史参考。
