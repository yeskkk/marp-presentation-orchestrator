# v0.9.5：整稿表达与审核发现

标题可删、规范学科语言、清楚自然的解释，以及独立句子分别起行，进入活动写作、编辑、五通道审核与输入契约。数学参考按任务学科路由，不污染非数学课程。结构检查只阻断明确的中文多句同段同显示行，排除代码、公式、链接等对象；不会自动改文，也不能取代语义审核。采用 Markdown 硬换行或分段，不放开 HTML/CSS。

返修最初的问题家族是优先目标，不是忽略五通道新发现的白名单。现有作者自修收到所有有效 findings，逐条处理或说明实际授权/事实冲突；不因“不属于本次焦点”弃置。仍不得擅自扩大课件范围、改动教学决策或增加作者自修后的 reviewer 轮次。

`repair open ... --focus student-expression` 显式登记全稿学生表达评价维度，覆盖选定稿的全部学生可见文字；不会静默改写原 TASK，也不把旧审核当成新标准通过。

验证：专门测试覆盖句子分行的正反例、学科路由和五通道旁发现转交作者闭环。原生 Marp 测试需要已安装的项目 Node 依赖；仅源码检查通过不等于成品渲染通过。旧归档缺少 PDF 时接续状态如实警告，不伪造文件。
