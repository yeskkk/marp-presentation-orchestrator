## FR-20260914-01：启动前选择并展示会话权限

- 用户需求：每次都要在会话开始后手动提升权限，希望 start.sh 在启动前提供选择；归类为功能增强，安排下次项目源码升级，不作为本次课件任务中的 bug 修复。
- 当前观察：启动器已有任务和 TASK 修改方向选择，但没有对应的权限选择菜单。本次原生浏览器最初因 socket 权限失败，用户调整权限并使新环境生效后，同一 toolchain doctor 通过。
- 建议行为：在启动模型会话前，让用户明确选择权限模式，展示文件系统、网络和命令审批的实际设置及适用范围，再按所选设置启动。提供对应非交互参数，保持各平台入口一致；明确哪些限制来自宿主、不能由启动脚本覆盖。
- 边界：不默认自动提权，不把任务确认、分稿确认或生产授权当成权限授权；不在运行中静默更改权限。具体选项和参数须在实现时核对所部署 CLI 的真实支持，不能只改提示文字或宣称权限已经生效。
- 验收：选择的设置准确传入会话；启动时显示实际采用值；取消不启动；不支持的组合明确报错；原任务 runtime 与生产确认规则保持不变。浏览器可用性仍由真实工具链检查验证。
- 状态：已登记，待下次源码升级设计与实现；本次未修改启动器。
