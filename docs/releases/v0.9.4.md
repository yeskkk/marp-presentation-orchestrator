# v0.9.4 — 旧 compact 任务接续与输入可靠性

合并 2026-09-15 运行副本 11 项差异：已发布整课拆分、越界写作守卫/真实退役、拒收纠正信息和有限引文规范化。
`task open <slug>` 在原目录自动完成必要 schema 兼容，并按发布/父子关系输出当前 leaf 版本，不重新初始化、不改变模型/授权、不改学生正文。
Runner 接续和新返修入口调用同一检查；旧父稿不再可作为新的返修目标。缺 PDF 明确显示，不伪造重新发布。
`source lines` / `source quote` 提供带源码 SHA256 的准确页内行号引用；reviewer 可以提交 source_ref，由程序提取原文，避免重复转抄 TeX。
资源预检和派发包列出真实 Python 解释器、固定 CLI 入口及模块可用性，不以探测成功当执行授权。
legacy 模板和旧模板专用验证脚本已经删除；旧文件制任务的只读 import-legacy 转换器保留。恢复旧生产引擎需要 Git 历史。

本版不进行模型语义返修。源文件和配置检查通过并不等于真实教学质量验收。详细回归日志随交付验证包提供。
