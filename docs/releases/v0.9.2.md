# v0.9.2 — 可审计的数据库保留与回收

累计包含 v0.9.1。schema 12 加迁移审计与维护记录；新增 storage inspect/migrate/prune/compact，保留策略 JSON 模板。只读检查不迁移；预览绑定指纹；应用需操作者和匹配计划；跨库部分完成如实登记。

共同维护锁防止 adapter、数据库写者、索引同步与维护并发。只回收可证实到期且冗余的正文；保留稳定行号、终态、计量、最终结果和所有课件文件。使用独立副本测试，不清理上传的原数据库。

未来门禁只存一份完整报告；线程恢复请求 excludeTurns=true，不在未知结果后自动重发。旧版协议不支持的错误显式返回。无默认提权，无新增模型调用。
