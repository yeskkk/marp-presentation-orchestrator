# v0.9.7 — 从已核验的 v0.9.6 增量重建

本版替代此前被拒绝的同号 v0.9.7 包。正式基线是用户提供的
`marp-presentation-orchestrator-v0.9.6-source.zip`，不是 v0.9.3，也不是旧 v0.9.7。

- 基线 ZIP SHA256：`a39b0569be68f35a36d4c63ce7d344e84ec1cd189d52946df70e0320c558e169`。
- 基线含 302 个常规文件；本版不删除其中任何文件。
- 原有测试文件全部保留，未放宽或删除原测试；新增测试另放在 `test_v097_*.py`。
- 活动 skill、模板、表达规则、旧任务兼容和当前检查点核心实现均从该基线保留。
- 被拒绝的旧包 SHA256：`c5139e0c46f64c006938db50589e102281fcaf2e0d750d95273483d1e22f2c25`。
  它只用于评估候选改动，不充当源代码基线。

## 1. 成本归属与筛选

`report usage` 增加 `--case`、`--batch`、`--since`、`--until`，可与重复的
`--presentation` 组合，所有条件取交集。新增按返修案、批次和 attempt 的汇总，保留原有
按角色、操作、课件的汇总与逐调用账本。

新 job 在实际绑定 attempt 的同一事务中固定归属；未知值也固定，后来的批次或课件状态不能
回填旧调用。历史记录只按明确关系、保留的返修请求或生产链条归属，不以日期、字符串碰巧
相同或当前 deck 的 repair_case 猜测。统计元数据不加入语义 worker 提示词。

schema 14 仅新增 `job_cost_context` 和 `scheduler_observation` 两张表；保留 schema 13
检查点、tombstone 和自动维护策略。只读报告兼容旧库，不为读取报告隐式迁移。

时间参数须带时区；until 为开区间。调用按有证据的开始时间整体选入，缺供应端时间时使用
实际账本记录时间并注明，不把一次调用按时间比例拆 token。缓存输入包含于输入，推理输出
包含于输出；金额和未知费用不猜测。

## 2. 可观察的等待状态

runner 在调度状态变化时记录确认、容量、资源/本地输入、执行对账等阻塞。相同状态的重复
tick 不重复累加；作用域改变时关闭旧段并开启新段。未结束的等待时长保持未知。

这些区间表示两次程序观测之间的状态，不证明程序停机期间一直阻塞，更不证明用户一直在
空等。报表不将旧时间空档自动补成原因；跨多稿/全任务的等待也不重复分摊给每个单稿。
按时间筛选闭合等待区间时只计算交叠部分。已有人工原因记录和前台接管机制保留。

## 3. 有界滚动 Codex bridge

一个真实结果被接受后，runner 可以接续独立的后继任务，不必等同批其他慢请求。并发上限
仍来自已确认 handle_limit，依赖、角色独立性、模型/强度及授权仍由原 runner 控制。
准入与回执接受串行化，供应端等待在锁外；新建 handle 及附着使用同一控制边界。

拒收、未知执行、容量/资源阻塞、重复 request ID、身份冲突或准入错误会停止新增派发。
已经派发的请求继续收取真实结果；不伪造取消，不因等待超时自动重发，不从旧 accepted 位
另造状态机。已清理请求的 v0.9.6 早期拒发守卫仍在。

`--cycles` 在 bridge 中限制准入 tick 次数，不再表示整批屏障次数；达到限额后收取在途结果
并交接 main。独立 command-adapter 仍沿用原执行方式，不宣称已改成滚动。

## 4. 基线回归修复

未经改动的 v0.9.6 全套测试中，篡改计算 SVG 的一次重复提交已经被正确拒绝，但错误信息
只写了“accepted revision 不同”，遮蔽了实际的 SVG 完整性原因。本版在仍然拒绝修改的前提
下追加真实检查错误。原测试保持不变，没有放宽完整性要求。

## 5. 验证范围

验证记录、基线逐文件清单、增量补丁和源码包哈希与本版一并提供。新测试包含：不可变归属、
只读旧库、迁移幂等、未知等待、时间交叠、停止新增并收齐在途结果、身份冲突，以及真实
Runner/Workflow 上独立编辑先于慢作者结束的确定性集成。

原始 `linear-algebra-v7` 归档的隔离副本用于升级、当前发布识别、清理后报告一致性验证。
归档缺少 PDF，维护测试显式使用归档例外；不宣称交付就绪，不放行生产门禁。没有调用真实
模型、改写实际五稿或更改模型强度。协议/门禁替身不等于真实 Codex、原生 Windows 或本轮
Marp/浏览器/PDF 渲染验收；本版不预报 token 节省比例。
